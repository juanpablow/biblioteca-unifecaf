# Biblioteca Digital UniFECAF

Primeira interface web da biblioteca digital da UniFECAF, desenvolvida com HTML e CSS para a disciplina Design Web.

**Site:** https://juanpablow.github.io/biblioteca-unifecaf/

**Vídeo pitch:** https://youtu.be/8mk4kACmOpg

## Estrutura

```
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── docs/
    ├── prototipo.png
    └── Relatorio-Biblioteca-UniFECAF.pdf
```

## Seções (conforme o protótipo em `docs/prototipo.png`)

Menu, banner, Sobre a nossa biblioteca, banner intermediário, Nossos livros, As unidades e Contatos.

## Decisões principais

- Paleta azul e laranja, com variáveis CSS e contraste verificado (WCAG AA).
- Layout com CSS Grid e breakpoints em 960px e 720px.
- Menu mobile apenas com CSS (checkbox + label).
- HTML semântico, skip link, foco visível e textos alternativos.
- Imagens autorais em SVG.

Os textos das unidades e dos contatos são genéricos (exemplo acadêmico).
